## สรุป

1. **จุดขายคือความน่าเชื่อถือ ไม่ใช่ความเร็ว:** เมื่อถูกบังคับปิดกลางทาง Chrome เริ่มโหลดใหม่ตั้งแต่ต้น ส่วนแอปเราโหลดต่อได้ และลิงก์หมดอายุก็ยังโหลดต่อได้ (ขั้นที่ 2)
2. **ความน่าไว้ใจคือสิ่งที่ผู้ใช้ห่วงมากที่สุด:** ห่วงยิ่งกว่าฟีเจอร์ใหม่ (ขั้นที่ 3)
3. **ฟีเจอร์ที่ควรทำต่อ เรียงตามลำดับ:**
   1. ตรวจการเชื่อมต่อกับ extension
   2. สแกนด้วย Microsoft Defender
   3. บันทึกความน่าเชื่อถือในเครื่อง
   4. เลือกหลายงาน

ระหว่างขั้นที่ 1 พบว่าไฟล์ที่แอปโหลดไม่มี Mark of the Web จึงแก้ในเวอร์ชัน 1.6.3
